# Pocket Agent v0.2.8

**Release Date**: 2026-06-11

Polish release: barge-in UX improvements, wake-word visual feedback, and settings readability.

## Highlights

### Barge-in improvements
- **Configurable barge-in sensitivity** — new slider in Settings controls the RMS threshold for interrupting AI speech (range 0.02–0.15, default 0.04). Higher = harder to interrupt
- **Barge-in toggle** — enable/disable barge-in independently of continuous conversation mode
- **Hysteresis release threshold** — once barge-in accumulation starts, RMS must drop below a lower threshold (0.02) to reset, preventing inter-syllable dips from clearing the tally
- **Tuned timing** — warmup 800→600ms, sustained speech requirement 400→350ms for snappier interrupts
- **Typewriter abort on barge-in** — immediately stop the typewriter animation so the user sees only what was already displayed, not stale text being flushed
- **Speaker verification on barge-in** — verifies the interrupting voice against enrolled speakers before sending to STT, preventing strangers from hijacking the conversation

### Wake-word visual feedback
- **Green breathing dot** — Dot 3 shows green breathing light when wake listener is active and idle (1.8s cycle)
- **Red breathing dot** — Dot 3 turns red when a `/wake/check` HTTP call is in progress (1.2s cycle), so the user can see exactly when PA is analyzing their speech
- **Instant state transition** — Rust emits `wake-checking`/`wake-check-done` events around each HTTP call, both on regular loop and timeout-flush paths

### Settings UX
- **Barge-in slider shows numeric value** — the sensitivity suffix now displays the actual threshold (e.g. `0.04 中`) instead of just `高/中/低`. All 7 UI languages updated
- **UI language selection persisted** — `ui_lang` stored in config and restored on launch

### Bug fixes
- **Wake Whisper only called on speaker match** — `/wake/check` no longer runs Whisper transcription when no enrolled speaker matches, avoiding the libiomp5 double-load crash on macOS Intel
- **stt-server traceback logging** — wake check errors now print full traceback for easier debugging
- **stt-server process lifecycle** — code fix now takes effect on restart (old process must be killed first: `kill $(lsof -ti :8651)`)
