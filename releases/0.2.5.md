# Pocket Agent v0.2.5

**Release Date**: 2026-05-29

Polish release focused on UI stability, streaming TTS timing, and window recovery. Addresses layout jitter when opening/closing the chat panel, hardens off-screen window recovery, and adds a non-blocking safeguard for the TTS queue.

## Highlights

### Layout stability
- **No more icon jumping** — removed Y-axis compensation in expand/collapse. Avatar is top-aligned in both states, so the window position no longer shifts when toggling the chat panel.
- **StatusPanel component** — thinking steps (`🤔 正在思考...`, `🔧 正在执行操作...`) moved from ChatPanel into a dedicated fixed-height StatusPanel. Thinking indicators appearing/disappearing no longer causes layout reflow.

### Off-screen window recovery
- **Monitor fallback** — when `currentMonitor()` returns null (window fully off all monitors), falls back to `availableMonitors()[0]` for primary monitor bounds before clamping.
- **Auto-reset** — saved position outside visible work area is automatically reset to a safe default.

### TTS queue safeguard
- **Non-blocking sentence callback** — `on_sentence` now checks `is_queue_full()` before enqueueing. When the audio queue is saturated, the sentence is skipped with a warning log instead of potentially blocking the stream delta handler.

### Streaming TTS timing fix
- **First-token trigger** — speaking animation now starts on the first stream delta (first real token from the LLM) instead of on `speaking-start`. Thinking steps remain visible until the model actually begins output.
- **Tool call protection** — `chat-audio-done` no longer prematurely finalizes the stream during tool call announcements.

## Files changed
- `src/App.svelte` — first-token speaking trigger, tool call TTS announcements, off-screen recovery with monitor fallback
