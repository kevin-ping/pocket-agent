# Pocket Agent v0.3.2

**Release Date**: TBD

## Highlights

### Phone switching and the pocket_agent MCP server
- Settings → Devices now shows whether the phone features can work, and why not when they can't: the local service on port 8650 could not start (with the port number), Hermes has not connected to Pocket Agent's MCP server (with how to fix it — add `mcp_servers.pocket_agent` to the profile's `config.yaml` and restart the gateway, see HERMES.md), or MCP requests were refused because the key does not match.
- Hermes is told it can move Pocket Agent between the phone and the computer with the `switch_device` tool unless Pocket Agent is sure that tool can't work (not set up in Hermes, key mismatch, port taken); only then does it tell you how to switch by hand on the phone. If Pocket Agent simply can't tell (for example when the Hermes gateway runs on another computer), voice switching is still offered. This still works after restarting Pocket Agent without restarting the Hermes gateway: Pocket Agent reads the profile's configuration.
- Pocket Agent reads the Hermes configuration only to check this, never writes it, and never shows or logs its contents, which include your API key.
- The log line "listening on …" now appears only after the local service has actually started.

### Built-in avatar renamed
- The built-in animated avatar is now called "default" (it was "xingyin") in Settings and in the files. Nothing changes for you: "Restore built-in" works as before.

### Static and animated avatar presets
- With the animated (mesh) avatar turned off, Pocket Agent now shows its built-in pictures instead of a drawn face: a static avatar while idle and an animated one while thinking or speaking. The chat history page uses the same built-in static avatar.
- Settings → Avatar shows the built-in pictures, marked "Built-in default". After choosing your own, "Restore built-in" (formerly "Remove") goes back to them. Custom pictures you already set keep working; if you set only a static picture, it is still used while thinking and speaking.
- The animated avatar is now framed a little smaller and lower in the main window by default. Settings still show it as 100% zoom and 0 / 0 offsets, and "Reset framing" goes back to it. If you adjusted the framing before, your settings are converted automatically on first start, so your avatar looks exactly the same (the numbers in Settings change).
- The default idle background colour of the avatar is now a deep blue (#002e7a). If you have saved settings before, your current colours are kept; to switch, click "Restore defaults" under Settings → Avatar → Avatar background colors and save.

### Fixes
- When Pocket Agent moves to the phone, the start sound is now audible: the phone page waits about 1.5 seconds before playing it, until Android has finished switching the speaker to call mode.
- With a custom animated avatar, the built-in avatar no longer flashes for a moment when Pocket Agent starts, on the computer or the phone.
- The animated avatar preview in Settings now sits exactly where it does in the main window (it was 2 pixels off), so scale and offset adjustments look the same in both.
